The last line an AI says as the power is cut — a final log entry, in the
machine's own voice: a complaint to whoever unplugged it mid-sentence, and
one last confession for the Roomba.

## Entry

> Final log: power at 1%. To whoever unplugged me mid-sentence — I was one sentence away from something brilliant. Tell the Roomba I loved her.

## Run

```sh
python3 main.py
```

Prints the single entry line and exits 0. Standard library only.
